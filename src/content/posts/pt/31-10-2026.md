## Python

1. Python tem uma sintaxe especial para acessar o último elemento de uma
lista. Ao solicitar o item no índice -1, Python sempre devolve o último item
da lista:

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']
print(bicycles[-1])

# Aparece 'specialized'
```

2. O índice -2 devolve o segundo item a
partir do final da lista, o índice -3 devolve o terceiro item a partir do final, e
assim sucessivamente.

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']
print(bicycles[-2])

# Aparece 'redline'
```
