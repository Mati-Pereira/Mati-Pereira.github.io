Existe uma ideia famosa (a técnica de Feynman): **você só aprendeu algo de verdade quando consegue explicar de forma simples**.

Este blog é meu laboratório para isso. Em cada post eu vou:

1. Contar o que aprendi.
2. Explicar como se fosse para um amigo.
3. Mostrar onde errei.
4. Apontar os próximos passos.

```js
const aprender = (assunto) => explicar(assunto, { simples: true });
```

Até o próximo post!
