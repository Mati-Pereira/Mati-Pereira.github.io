There's a famous idea (the Feynman technique): **you only truly learned something when you can explain it simply**.

This blog is my lab for that. In each post I will:

1. Say what I learned.
2. Explain it as if to a friend.
3. Show where I got it wrong.
4. Point out next steps.

```js
const learn = (topic) => explain(topic, { simple: true });
```

See you in the next post!
